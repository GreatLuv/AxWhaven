# AxWhaven — Complete Project Architecture & Master Refinement Prompt

---

## Part 1: Project Overview & Tech Stack

**AxWhaven** is a native Android anime wallpaper manager built with modern Jetpack Compose. It combines bundled offline curated collections with online discovery across 8 image providers (Wallhaven, Safebooru, Danbooru, Gelbooru, Konachan, Yande.re, Anime-Pictures, and Pixiv), custom Storage Access Framework (SAF) directory management, and a unified Material 3 Expressive + Frosted Glassmorphism visual design system.

### Tech Stack & Toolchain
- **Language:** Kotlin 2.1+ (JvmTarget JVM 17)
- **UI Toolkit:** Jetpack Compose (Compose BOM 2026.05.01, Material 3 1.4+, Material Icons Extended)
- **Architecture:** Unidirectional Data Flow (UDF) with MVVM (`WallpaperViewModel` + `WallpaperUiState` via `StateFlow`)
- **Image Loading:** Coil 2.7.0 (`io.coil-kt:coil-compose`) with custom multi-layer memory/disk caching and hardware bitmaps
- **OS Compatibility:** `minSdk = 24` (Android 7.0), `compileSdk = 37`, `targetSdk = 37` (Android 17 preview / Android 15/16)
- **Build System:** Gradle 9.8.2 / AGP 9.2.1, with AndroidX Profileinstaller 1.4.1 for Ahead-of-Time (AOT) baseline profiles
- **Build Commands:**
  - Debug APK: `studio build . :app:assembleDebug`
  - Release APK: `studio build . clean :app:assembleRelease`
  - Location: `app/build/outputs/apk/release/AxWhaven_1.0.apk` and `app/build/outputs/apk/debug/app-debug.apk`

## Part 3: UI Files & Responsibilities Breakdown

### 1. Root & Navigation
* **`MainActivity.kt`**
  - **Role:** Application entry point and root composable host.
  - **Responsibilities:**
    - Initializes Android 12+ native splash screen (`installSplashScreen()`) with state readiness gate.
    - Sets edge-to-edge system insets (`enableEdgeToEdge()`).
    - Configures root `BackHandler`: exits only on Home tab root; gracefully traverses through active wallpaper preview -> filter bottom sheet -> collection detail folder -> previous tabs.
    - Manages SAF directory pickers for custom storage and pre-uninstall wallpaper backup.
    - Renders ambient luminous radial gradient backdrops (optimized for zero redundant blur passes).
    - Hosts the root `Scaffold` and floating dock `AxWhavenBottomNavBar`.
    - Coordinates directional horizontal page transitions (`slideInHorizontally` + `scaleIn` + `fadeIn` powered by `ExpressiveMotion.DefaultSpatialIntOffset/Float`).
    - Houses the full-screen `WallpaperPreviewScreen` modal layer above the scaffold.

### 2. Design System & Theme Engine
* **`ui/theme/ThemeConfig.kt`**
  - **Role:** Single source of truth for design tokens, themes, and dynamic palettes.
  - **Key Tokens & Constants:**
    - `FloatingDockClearance = 150.dp`: Universal bottom padding ensuring scrollable lists are never obscured by the floating dock.
    - `AppThemeMode`: `EXPRESSIVE` (M3 dynamic tonal surfaces), `AMOLED_BLACK` (pure #000000 OLED), and `FROSTED_GLASS` (translucent frosted acrylic).
    - `PixelPaletteSeed`: 6 Pixel-style swatches (`SYSTEM`, `LAVENDER`, `GOLDEN_AMBER`, `SAKURA_ROSE`, `CYBER_CYAN`, `MONOCHROME`).
    - `AxWhavenColors`: Unified color contract providing background, surface, surfaceElevated, cardBorder, glassBlur, primaryAccent, textPrimary, textSecondary, etc.
* **`ui/theme/ExpressiveMotion.kt`**
  - **Role:** Physics-based animation tokens adhering to Material 3 Expressive guidelines.
  - **Spatial Springs (Damping 0.6–0.8 with natural overshoot for position, size, scale):**
    - `FastSpatial`: `dampingRatio = 0.6f`, `stiffness = 800f` (pill sliders, dice button, icon pops).
    - `DefaultSpatial`: `dampingRatio = 0.8f`, `stiffness = 380f` (page slides, header collapsing).
    - `SlowSpatial`: `dampingRatio = 0.8f`, `stiffness = 200f` (full-screen sheet expansions).
  - **Effects Springs (Critically damped, Damping = 1.0f with zero bounce for color, alpha, elevation):**
    - `FastEffects`: `dampingRatio = 1.0f`, `stiffness = 3800f` (press highlights, icon tints).
    - `DefaultEffects`: `dampingRatio = 1.0f`, `stiffness = 1600f` (fades, container color shifts).
* **`ui/theme/Theme.kt`**
  - **Role:** Applies Material 3 `MaterialTheme` and binds `LocalAxWhavenColors`.
* **`ui/theme/Type.kt`**
  - **Role:** Defines typography hierarchy using Material 3 Expressive type scales.
* **`ui/theme/Color.kt`**
  - **Role:** Low-level color definitions and hex constants.

### 3. Reusable UI Components
* **`ui/components/BottomNavBar.kt`**
  - **Composables:** `AxWhavenBottomNavBar`, `NavBarItem`.
  - **Responsibilities:**
    - Floating pill navigation dock (Home, AxW Surf, Settings).
    - Liquid stretch sliding pill indicator that morphs in the direction of motion.
    - Optimized draw-phase execution: reads animated tab indices strictly inside `Modifier.graphicsLayer { ... }` to guarantee 0 recompositions during 60–120Hz spring motion.
    - Layout-phase icon offset via `.offset { IntOffset(0, y) }` and haptic feedback triggers (`HapticFeedbackType.TextHandleMove`).
* **`ui/components/GlassmorphicBadge.kt`**
  - **Composables:** `GlassmorphicBadge`.
  - **Responsibilities:** Renders frosted glass badges on collection and wallpaper cards with glowing status dots.
* **`ui/components/M3ExpressiveMorphingLoader.kt`**
  - **Composables:** `M3ExpressiveMorphingLoader`, `ContainedLoadingIndicatorFallback`.
  - **Responsibilities:** Smooth shape-morphing loading spinner matching Android 17 Google Pixel expressive guidelines.
* **`ui/components/WallpaperImage.kt`**
  - **Composables:** `WallpaperImage`.
  - **Responsibilities:** Efficient Coil image rendering with placeholder crossfade, hardware bitmap support, error recovery, and optional background blur scaling.

### 4. Primary App Screens
* **`ui/screens/HomeScreen.kt`**
  - **Composables:** `HomeScreen`, `CleanWallpaperCard`, `CollectionArtCard`, `StandaloneDiceButton`, `RandomDieTargetDialog`, `DieOptionButton`.
  - **Responsibilities:**
    - Displays offline curated collections and wallpaper grids.
    - Smooth scroll-responsive collapsing header: header and dice button vanish seamlessly on scroll down and reappear on scroll up.
    - Segmented pill tab switcher (All Wallpapers vs Collections) with spring sliding indicator.
    - Random dice roll button with physics-based roll animation and target selection modal (Home, Lock, Both).
    - Interactive card press morphing (squircle corner radius expands from 20.dp to 28.dp on press).
    - Explicit `contentType = { "wallpaper_card" }` for optimal `LazyVerticalGrid` recycling.
* **`ui/screens/HavenSurfScreen.kt`**
  - **Composables:** `HavenSurfScreen`, `HavenSurfResultCard`, `HavenSurfFilterModalSheet`, `FilterPillItem`, `ProviderCookieDialog`, `DownloadQualityDialog`, `DownloadOptionCard`.
  - **Responsibilities:**
    - Online discovery feed across 8 anime wallpaper/booru engines.
    - Pill-shaped search bar with real-time tag query suggestions and keyboard visibility awareness.
    - Horizontal provider selector with interactive chip morphing and badge counts.
    - Two-column staggered/vertical wallpaper grid with infinite scrolling pagination.
    - Download button with interactive progress loader, checkmark completion animations, and download quality modal (Original vs Compressed).
    - Built-in cookie bypass dialogs for Cloudflare-protected providers (Konachan, Danbooru).
    - Filter bottom sheet (`HavenSurfFilterModalSheet`) for aspect ratio, resolution, and content rating.
* **`ui/screens/SettingsScreen.kt`**
  - **Composables:** `SettingsScreen`, `PixelPaletteSwatch`, `ExpressiveFilterChip`, `ExpressiveActionButton`, `SettingsSectionHeader`.
  - **Responsibilities:**
    - Appearance customization: Theme mode picker (Material 3 Expressive, AMOLED Black, Frosty Glass).
    - Pixel-style 6-swatch Color Palette row (System, Lavender, Golden Amber, Sakura Rose, Cyber Cyan, Monochrome) with outer selection rings.
    - Background blur slider with tactile snap ticks and interactive spring physics.
    - Custom Storage Access Framework (SAF) folder picker, default reset, and live storage statistics.
    - Wallpaper backup actions (Export to Pictures / External Folder) and clean uninstall helper.
* **`ui/screens/WallpaperPreviewScreen.kt`**
  - **Composables:** `WallpaperPreviewScreen`, `TargetSelectionModalDialog`, `SegmentedTargetOptionRow`.
  - **Responsibilities:**
    - Immersive edge-to-edge wallpaper preview modal.
    - Gesture-driven zoom and pan with spring-back physics.
    - Aspect ratio display mode toggle: Screen Fit (contain) vs Screen Fill (crop).
    - "Set Wallpaper" action launching `TargetSelectionModalDialog` (Home Screen, Lock Screen, Both Screens) with haptic feedback.
    - Options to set as in-app custom background wallpaper or launch the system wallpaper picker.
